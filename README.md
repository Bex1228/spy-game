# Шпион

Mobile-first party-игра «Шпион» для компании с одного телефона. Без backend, аккаунтов и базы данных: всё работает в браузере, настройки и история слов хранятся в `localStorage`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Проверки и сборка:

```bash
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm run build      # production-сборка (Vercel использует её же)
npm run start      # запуск собранной версии
```

## Как играть

1. На главном экране нажмите «Быстрая игра» (последние настройки или дефолты) или «Настроить игру».
2. Телефон передаётся по кругу: каждый игрок удерживает карточку, чтобы увидеть роль, затем скрывает её.
3. Приложение называет, кто задаёт первый вопрос, и запускает таймер.
4. После раунда — голосование и экран результатов с раскрытием шпиона.

## Структура

```
src/
  app/          layout, page, глобальные стили и self-hosted шрифты
  screens/      экраны: Home, Setup, Reveal, RoundStart, Timer, Results
  components/
    ui/         переиспользуемые элементы (Button, Stepper, Sheet, …)
    game/       игровые компоненты (RoleCard, TimerRing, CategoryTile, …)
  game/         чистая игровая логика: правила, генерация раунда, история слов, конечный автомат
  data/         встроенные категории и слова
  hooks/        таймер, удержание карточки, хранилище, вибрация, защита от «Назад»
  types/        общие типы
  utils/        random, storage, форматирование
public/fonts/   Unbounded и Manrope (кириллица + латиница)
```

## Добавить категорию

Создайте файл в `src/data/categories/` по образцу существующих и добавьте его в `BUILTIN_CATEGORIES` в `src/data/index.ts`. Структура уже допускает пользовательские категории (`source: "custom"`) и уровни сложности слов.
